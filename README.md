# SKS Department - Full-Featured Web Application & Admin Dashboard

> **(Source code restricted for institutional privacy).** This public repository serves solely as a portfolio overview of a comprehensive enterprise system prototype developed for campus management.

---

## Project Overview
This project is a robust, full-featured web application and administrative dashboard prototype built to digitalize the web presence and operational workflows of a university's Health, Culture, and Sports (**SKS**) department. It functions as a complete Content Management System (CMS) tailored for institutional transparency, student services, and departmental coordination.

## Key Modules & Features

### 1. Administrative Dashboard (CMS & Control Panel)
* **Dynamic Content Management:** Dedicated interfaces to publish and manage homepage sliders, campus news, and official announcements.
* **Document & Form Management:** Centralized system to upload and organize institutional directives, student petitions, and downloadable forms.
* **Role-Based Access Control:** Secure backend infrastructure managing administrator privileges across different departmental modules.

### 2. Departmental Services & Modules
* **Student Clubs & Culture:** A structured directory for active student clubs, establishment procedures, and cultural activity announcements.
* **Health & Psychological Counseling (PDR):** Informational portals detailing campus clinic operations, emergency procedures, and psychological support services.
* **Sports Services:** Modules to showcase university sports teams, intramural tournaments, and facility guidelines.
* **Dining Services:** Dedicated section for publishing daily/monthly cafeteria menus and catering announcements.
* **Student Support & Accessibility:** Specialized hubs for the Barrier-Free Campus initiatives and Part-Time Student Employment programs.

## Technical Architecture & Tech Stack

The platform is built on a modern, decoupled client-server architecture, utilizing a RESTful API approach for seamless data communication.

### Frontend (Client-Side)
* **Core:** React 18, TypeScript, Vite (Build Tool & Dev Server)
* **Routing:** React Router DOM for dynamic client-side navigation
* **Styling & UI:** Tailwind CSS (utility-first styling), PostCSS, Autoprefixer, and Lucide React for iconography

### Backend (Server-Side & API)
* **Core Environment:** Node.js with Express.js framework (JavaScript)
* **Authentication & Security:** JSON Web Tokens (JWT) for secure session management, bcryptjs for robust password hashing, and CORS handling
* **API Design:** RESTful endpoints managing administrative actions and data retrieval
